리더 소개

현실적인 고민을 함께 짚어 보는 타로 리더, 유희입니다.

Butterfly Tarot Reader
유희
“앞으로 내 돈·일·공부는 잘 흘러갈까?”라는 고민에 특화된 리딩을 진행합니다.
막연한 위로보다는, 현재의 흐름 + 현실적인 조언을 같이 보는 스타일입니다.
  • 진행 방식 : 텍스트 리딩 + 카드 사진
  • 주요 주제 : 금전운, 취업·이직, 시험·합격, 진로 방향
  • 사용 언어 : 한국어
💬 리딩 스타일
· “될까요/안 될까요?”보다 “어떻게 하면 더 잘 될까?”에 초점을 맞춥니다.
· 부담스럽지 않은 톤으로, 필요한 부분은 솔직하게 이야기합니다.
진행 안내
  • 진행 채널 : 카카오톡 오픈채팅
  • 결과 전달 : 카드 사진 + 상세 텍스트
  • 추가 질문 : 같은 리딩에 연결된 짧은 질문 1회 가능
  • 예약 : 아래 양식 작성 후 카카오톡으로 전송
📌 이런 분께 특히 추천해요
· 취업 준비, 이직, 알바 선택 등 진로 고민이 많은 분
· 시험, 자격증, 합격운이 궁금한 분
· 요즘 금전운이 답답하게 느껴지는 분

커미션 요금

시간제 상담과 개별 질문 리딩으로 진행됩니다. (금액은 상황에 따라 조정 가능합니다)

15 min
15분 채팅 상담
짧은 질문 1~2개를 빠르게 보는 기본 옵션입니다.
10,000원
· 채팅 상담 약 15분
· 핵심 카드 중심 간단 해석
*짧은 시험운, 당장의 금전 흐름 등을 볼 때
예) “이번 달 알바 계속 해도 될까?”, “다가오는 시험의 분위기는 어떤지?”
20 min
20분 채팅 상담
현재 상황·앞으로의 흐름·조언까지 함께 보는 기본 심화 리딩입니다.
15,000원
· 채팅 상담 약 20분
· 카드 여러 장 사용
*취업/이직 방향, 재정 계획, 시험 준비 흐름 등에 적합
예) “공무원 준비 vs 취업, 어느 쪽이 나에게 더 맞을까?”,
“올해 금전 흐름과 주의할 점은?”
30 min
30분 채팅 상담
여러 요소가 얽힌 고민을 장기 흐름까지 함께 보는 심층 리딩입니다.
20,000원
· 채팅 상담 약 30분
· 복수 스프레드 활용 가능
*취업·이직·시험·금전이 동시에 얽힌 상황에 추천
예) “올해~내년까지 진로·금전·시험 흐름을 전체적으로 보고 싶어요” 같은 요청에 적합합니다.
Q&A
개별 질문 리딩
질문 하나에 집중해서 간단히 방향만 빠르게 보고 싶을 때 선택합니다.
한 질문당 5,000원
· 단일 질문 한 가지
· 짧은 텍스트 + 카드 사진
*명확한 한 문장 질문에 가장 잘 맞아요
예) “이번 면접은 나와 잘 맞는 곳일까요?”, “이번 시험에 합격 가능성이 있을까요?”

타로 리딩 종류

모든 요금 옵션에서 아래 리딩 종류 중 하나(또는 두 가지)를 선택해 진행할 수 있습니다.

💸 금전운 · 재물 흐름
현재 수입·지출 패턴, 돈이 들어오고 나가는 흐름,
앞으로의 재정 분위기와 주의해야 할 지점을 봅니다.
💼 취업 · 이직 · 진로
현재 준비 방향이 나에게 맞는지, 어떤 환경에서 더 잘 맞는지,
진로/직무 선택에 대한 힌트를 함께 찾습니다.
📚 시험 · 자격증 · 합격운
이번 시험·자격증의 에너지, 준비 방향, 보완해야 할 부분과
마음가짐에 대한 메시지를 중심으로 리딩합니다.
📅 일정 · 계획 흐름
여러 계획이 한꺼번에 겹쳐 힘들 때, 기간별 흐름을 보며
언제 힘을 써야 할지, 어떤 순서가 좋을지 정리해 드립니다.

진행 방식

신청부터 결과를 받아보기까지, 유희 타로의 기본 흐름입니다.

1
신청 양식 작성
아래 양식을 복사해 카카오톡으로 보내 주세요.
(이름, 리딩 종류, 질문 등)
2
시간 · 옵션 안내
가능 여부를 확인 후, 예상 진행 시간과
금액, 전달일을 안내드립니다.
3
입금 확인 후 리딩
입금이 확인되면 카드를 펼치고,
텍스트로 차분히 정리합니다.
4
결과 전달 · Q&A
카드 사진과 해석을 전달한 뒤,
관련된 짧은 추가 질문 1회까지 가능해요.
유희 타로 신청하기
아래 양식을 복사해 카카오톡으로 보내 주시면,
가능한 일정과 옵션을 확인한 뒤 순서대로 안내드릴게요.
예약 양식
  • ① 이름(또는 닉네임) :
  • ② 희망 옵션 (15분 / 20분 / 30분 / 개별 질문) :
  • ③ 리딩 종류 (금전 / 취업·이직 / 시험·합격 / 일정흐름 중 택1~2) :
  • ④ 질문 내용 (가능한 한 구체적으로) :
  • ⑤ 희망 전달 기한 (급한 경우 표시) :

질문을 어떻게 정리해야 할지 애매하다면,
“이 상황을 어떤 식으로 물으면 좋을지”부터 함께 잡아 드립니다.
